# Water Consumption Analysis

## Overview
This project analyses water consumption data using Python and Jupyter Notebook to identify usage patterns and generate insights.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
- water_usage.csv

## Features
- Data cleaning
- Exploratory Data Analysis (EDA)
- Visualizations
- Insights and conclusions

## How to Run
1. Clone the repository.
2. Install the required libraries.
3. Open `water_consumption_analysis.ipynb` in Jupyter Notebook.
4. Run all cells.
